# SQL GroupBy & Partitioning Practice — @hellrover

A set of LeetCode-style SQL problems worked through to build up `GROUP BY`
aggregation and window-function (`PARTITION BY`, `ROW_NUMBER`, `RANK`, etc.)
skills — the two patterns that come up constantly in SQL interview questions.

## What's here

Each problem lives in its own folder under `SQL/` with the prompt (`.md`)
and the submitted solution (`.sql`):

```
SQL/
  <problem-name>/
    <problem-name>.md   ← problem statement
    submission-0.sql     ← solution
```

## Focus areas

- **`GROUP BY` aggregation** — e.g. `sql-top-travellers`,
  `sql-customers-bought-a-b-not-c`
- **Window functions / `PARTITION BY`** — e.g.
  `sql-highest-grade-for-each-student`

Solutions were synced from [NeetCode.io](https://neetcode.io) via its
GitHub Sync integration.
